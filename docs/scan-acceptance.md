# 移动端扫码验收

## 功能范围

工作台、服务目录和各业务列表统一进入扫码页。支持库存（物料编码）、采购入库、生产领料、销售出库、生产订单和销售订单编号查询。全局入口按当前用户权限展示查询业务，默认库存查询；没有库存权限时使用第一个可查询业务。查询沿用现有列表的状态范围和当前仓库条件，不会自动改变仓库或提交业务操作。

- App / 小程序：调用原生扫码，支持条码与二维码；按平台能力提供相册入口。
- H5：使用本地 ZXing 解码相机视频，优先后置镜头；需要 HTTPS 或 localhost。视频不上传服务端。
- 手工 / PDA：编码输入框支持键盘、粘贴和以回车结束的扫码枪输入。
- 识别后先核对，再点击查询；从列表进入时确认后回传原列表，取消不改变筛选。
- 支持纯编码，保留前导零和大整数 ID；最多 200 字符。链接、JSON、控制字符会明确提示改扫业务编码，不会自动打开地址或猜测业务 ID。
- 相机拒绝、占用、缺失以及不安全地址均有恢复提示；退出、后台或识别完成时释放 H5 相机。
- 新查询覆盖仍在加载的旧查询，旧响应不会覆盖新结果。

## 真机验收清单

1. 工作台和服务目录进入扫一扫，扫码 `001234`，核对后查询库存，确认前导零保留且仓库条件一致。
2. 分别从四个单据列表和库存、生产订单、销售订单列表进入，扫码后确认，检查回传和查询条件；取消后检查原条件未变。
3. 限权账号只显示可查询业务；无业务权限账号出现说明，不执行越权查询。
4. H5 分别扫描二维码、Code 128、EAN 条码；普通局域网 HTTP 出现 HTTPS 提示，手输仍可查询。
5. 拒绝权限、相机被占用、无摄像头时检查提示；设置中授权后重试。
6. H5 相机授权弹窗未完成时返回、扫码过程中返回/切后台、识别成功后，确认相机指示灯熄灭。
7. 连点扫码、连续扫描同一码，只有一次结果；旧请求较慢时，新编码结果不被覆盖。
8. PDA 输入框获得焦点后扫码并回车；断网时保留编码，联网后重试。
9. 320 / 390 / 430 像素宽度和大字体下检查按钮、错误信息和业务选择；无结果后可回列表清除筛选。

## 发布条件

- 原生 App 需在 HBuilderX 中配置 AppID、签名并重新打包；已配置 Barcode 模块和 iOS 相机/相册用途说明。
- 小程序需配置自身 AppID 和合法请求域名。
- 构建资源通过不等同于真实摄像头验收；上线前完成上述设备测试。

平台契约参考：[uni.scanCode](https://uniapp.dcloud.net.cn/api/system/barcode.html)、[App 模块配置](https://uniapp.dcloud.io/tutorial/app-modules.html)。
